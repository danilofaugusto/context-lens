# Context Lens

Use this skill when you want to view, inspect, or manage token usage across the conversation.

## Open the Side Pane

Click the link below to toggle the Context Lens in the auxiliary side pane:

[Open Context Lens](sidecar://context-lens/lens/)

## Capabilities
- Visual color-coded usage bar.
- Interactive token breakdown for Tools, Rules, Skills, and Turns.
- Projected token growth for incoming message.
- Session quick actions (Compaction trigger, detailed inspection).
